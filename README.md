# Ley 21.719 Chile — Web Educativa Interactiva

Plataforma educativa interactiva sobre la **Ley N° 21.719 de Protección de Datos Personales** de Chile. Curso en línea con módulos temáticos, quizzes, checklist y certificación.

## 📚 Documentación Complementaria

- **[ley21719-cl-docs](https://github.com/halconxhermes-droid/ley21719-cl-docs)** — Repositorio de documentación complementaria:
  - 📕 Informe SENCE completo (cómo obtener código oficial de capacitación)
  - 📘 Guías de materiales
  - 📝 Recursos de apoyo

## Stack

- React 19 + TypeScript + Vite 6 + Tailwind 4 (frontend)
- FastAPI + Python 3.13 + SQLite/PostgreSQL (backend)
- InsForge (PostgreSQL gestionado)
- Netlify (deploy frontend) + Fly.io (deploy backend)

## Estructura

- `frontend/` — SPA React
- `backend/` — API FastAPI
- `design/` — Mockups, HTML, estilo visual
- `docs/` — Contenido del curso (módulos, quizzes, glosario)
- `tools/` — Manuales y herramientas auxiliares
